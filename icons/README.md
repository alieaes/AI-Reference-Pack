# Icon References

개발 및 UI 작업에 활용할 수 있는 아이콘/아이콘 리소스.

- [Phosphor Icons](https://phosphoricons.com/) — 무료 SVG 아이콘 모음. 다양한 스타일과 굵기의 아이콘을 제공하며 UI/웹/앱 개발에 활용하기 좋음.
- [Iconsax](https://iconsax.io/) — Vuesax 기반 아이콘 라이브러리. 7,000개 이상의 무료 아이콘과 다양한 스타일을 제공하며 React, Vue, Svelte, TypeScript 등에 활용 가능.
- [Pixelarticons](https://pixelarticons.com/) — 픽셀 아트 스타일의 아이콘 라이브러리. 24×24 그리드 기반의 픽셀 아이콘을 제공하며 SVG, 웹폰트 및 React/Vue/Svelte 등에서 활용 가능.
- [Boxicons](https://boxicons.com/) — 현대적인 UI/제품 디자인용 아이콘 라이브러리. Basic, Filled, Duotone 등의 스타일과 Regular/Rounded/Sharp 형태를 제공하며 무료 아이콘은 개인·상업 프로젝트에 사용 가능.
- [Remix Icon](https://remixicon.com/) — 오픈소스 중립 스타일 아이콘 시스템. 웹/앱 UI에 적합한 다양한 SVG 아이콘을 제공하며 개인 및 상업적 용도로 무료 사용 가능.
