# UI Component References

실제 개발에 활용할 수 있는 UI 컴포넌트, 복사 가능한 코드, 인터랙티브 컴포넌트 및 컴포넌트 라이브러리 레퍼런스.

- [Uiverse](https://uiverse.io/elements) — 커뮤니티에서 만든 오픈소스 UI 요소 모음. HTML/CSS, Tailwind, React, Figma 등에 활용할 수 있는 버튼, 카드, 폼, 로더, 토글 등의 컴포넌트를 제공.
- [21st.dev](https://21st.dev/) — React/Next.js + Tailwind 기반의 고품질 UI 컴포넌트 및 페이지 블록 모음. 버튼, 카드, 폼, Hero, Navigation, Dashboard, Animation 등 다양한 컴포넌트를 제공.
- [Anime.js](https://animejs.com/documentation) — JavaScript 기반 애니메이션 라이브러리. DOM, CSS, SVG, JavaScript 객체 등을 대상으로 타임라인, 키프레임, 이징, 스태거, SVG 애니메이션 및 인터랙티브 모션을 구현할 때 활용할 수 있음.
